Drop authentic Foundation photographs here using these exact filenames.
Until a file exists, the page shows a labelled placeholder in its place.

|--------------------------|--------------------|--------------------------------------------|-----------------|
| `hero.webp`              | Hero               | Portrait (already added)                   | 1200 × 1200     |

| `gallery-teacher.jpg`    | Impact gallery     | Teacher leading a lesson                   | 800 × 1000      |
| `gallery-youth.jpg`      | Impact gallery     | Youth activity                             | 800 × 1000      |
| `gallery-community.jpg`  | Impact gallery     | Community event                            | 800 × 1000      |

Export as JPEG (quality ~75–80) or WebP, ideally under 250 KB each.
If a photo's subject differs, update its `alt` text in `index.html`.
