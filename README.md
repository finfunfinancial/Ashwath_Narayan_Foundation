# Dr. C.N. Ashwathnarayan Foundation — Website

Static homepage (HTML, CSS, JS — no build step).

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080/.

## Structure

- `index.html` — page content
- `css/styles.css` — styles
- `js/main.js` — mobile menu, nav highlighting, scroll reveals
- `assets/images/` — photographs (see the README there for file names)
